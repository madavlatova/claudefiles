# ИИ в деятельности педагогического дизайнера: интерактивная презентация

Один файл `index.html`, работает без интернета. Магистерская программа «Педагогический дизайн», НИУ ВШЭ.

Управление: стрелки или кнопки на краях экрана, `F` – полный экран, `O` – обзор слайдов, `N` – заметки докладчика.

Онлайн: https://madavlatova.github.io/claudefiles/ii-pedagogicheskiy-dizayn/
