# Опрос семинара (аналог Menti)

Студенты отвечают с телефона по обычной ссылке, без аккаунтов. Вы видите ответы на экране сразу и сами переключаете вопросы.

## Как это работает
- `index.html` — вся страница. Студенты открывают её по ссылке, вы открываете ту же ссылку с `#host` в конце и входите по почте и паролю.
- Ответы хранятся в бесплатной базе Firebase Realtime Database. Студенты могут только отправлять ответы. Читать ответы и менять вопросы можете только вы.
- Страница обновляется каждые 2 секунды.

## Настройка за 10–15 минут
1. Откройте https://console.firebase.google.com, войдите аккаунтом Google, нажмите «Создать проект» (аналитику можно отключить).
2. Слева: «Сборка» → «Realtime Database» → «Создать базу данных». Регион: europe-west1. Режим: «заблокированный».
3. Вкладка «Правила». Откройте файл `database.rules.json`, замените `ВАША_ПОЧТА@gmail.com` на вашу почту (3 места), вставьте содержимое целиком и нажмите «Опубликовать».
4. «Сборка» → «Authentication» → «Начать» → способ входа «Почта/пароль» → включить. Вкладка «Users» → «Добавить пользователя»: ваша почта (та же, что в правилах) и придуманный пароль.
5. Значок шестерёнки → «Настройки проекта» → «Общие» → внизу «Ваши приложения» → значок `</>` (веб-приложение), любое имя. Скопируйте `apiKey`. Адрес базы `databaseURL` виден на странице Realtime Database вверху (вида `https://...firebasedatabase.app`).
6. Откройте `config.js`, вставьте `apiKey`, `databaseURL` и вашу почту.

## Публикация на GitHub Pages
1. На github.com: «New repository» (например, `opros`), публичный.
2. «Add file» → «Upload files»: загрузите `index.html`, `config.js`, `README.md` (файл правил `database.rules.json` загружать не нужно). «Commit changes».
3. «Settings» → «Pages» → Source: «Deploy from a branch», ветка `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты ссылка будет `https://ВАШ_ЛОГИН.github.io/opros/`. Её даёте студентам. Себе: та же ссылка с `#host` на конце.

## На занятии
1. Откройте ссылку со `#host`, войдите. Перед занятием нажмите «Анкета студента» и пройдите опрос сами, затем «Настройки» → «Очистить все ответы».
2. Покажите студентам ссылку или QR-код.
3. Кнопкой «Следующий вопрос» открывайте вопросы. Студенты видят текущий вопрос, вы видите диаграмму.
4. После занятия: «Настройки» → «Скачать CSV».

## Что стоит знать
- Без заполненного `config.js` страница работает в демо-режиме: ответы хранятся в браузере, видны только в соседней вкладке.
- Правила разрешают любому, у кого есть ссылка, отправить ответ. Для учебного опроса этого достаточно, для чувствительных данных не подходит.
- Не загружайте на GitHub пароль. В `config.js` лежат только адрес базы и ключ приложения; ключ приложения Firebase не секретен, защиту дают правила.
- Вопросы и варианты ответов меняются в начале скрипта в `index.html` (список `Q`).
